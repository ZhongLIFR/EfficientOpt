# CP low-rank demand tensor ridge shrinkage

A commerce platform estimates a customer-product-week demand adjustment tensor X with 130 customers, 120 products, and 90 weeks. The target tensor T is not listed entry by entry. It is generated by a rank-4 CP decomposition:

T[i,j,k] = sum_r A[i,r] * B[j,r] * C[k,r].

Choose a real-valued tensor X to minimize:

0.5 * ||X - T||_F^2 + 0.5 * lambda * ||X||_F^2

with lambda = 0.38. The deterministic formulas for A, B, and C are listed in `instance.json`.

Report the minimum objective value and the squared Frobenius norm of the optimal X.

The dense formulation treats X as 1,404,000 independent scalar variables. A tensor-aware formulation keeps the CP factors and computes the optimum by Gram-matrix identities.
