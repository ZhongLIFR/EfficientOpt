# Tucker-core campaign response tensor model

A planning team models a region-product-week response tensor through known regional factors A, product factors B, week factors C, and an unknown Tucker core tensor G with size 3 x 4 x 3:

X = G x_1 A x_2 B x_3 C.

The target response tensor is generated by a deterministic reference core G0:

Y = G0 x_1 A x_2 B x_3 C.

Choose G to minimize:

0.5 * ||X - Y||_F^2 + 0.5 * lambda * ||G||_F^2

with lambda = 0.52. The deterministic formulas for A, B, C, and G0 are listed in `instance.json`.

Report the minimum objective value and a checksum of the optimal core tensor.

The dense formulation expands every region-product-week entry and builds a large entrywise design. A tensor-aware formulation keeps the Tucker structure and solves only the 36 core parameters using mode Gram matrices.
