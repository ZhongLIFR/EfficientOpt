# Low-rank response matrix ridge shrinkage

A retail platform estimates a store-by-product promotion response matrix X with 840 stores and 690 products. The target response matrix is not listed entry by entry. It is generated by two rank-5 factor matrices U and V:

A = U V^T.

Choose a real-valued response matrix X to minimize:

0.5 * ||X - A||_F^2 + 0.5 * lambda * ||X||_F^2

with lambda = 0.42. The deterministic formulas for U and V are listed in `instance.json`.

Report the minimum objective value and the squared Frobenius norm of the optimal X.

The dense formulation treats X as 579,600 independent scalar variables. A matrix-aware formulation keeps the rank-5 factorization and solves the shrinkage by Gram-matrix identities.
