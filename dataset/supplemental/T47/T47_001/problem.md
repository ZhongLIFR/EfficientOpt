# Low-rank core modeling for segment-item price response

A pricing team models a segment-by-item response matrix through known segment features P, known item features Q, and an unknown 4-by-4 interaction core C:

X = P C Q^T.

The reference response matrix is generated by a deterministic core C0:

Y = P C0 Q^T.

Choose C to minimize:

0.5 * ||P C Q^T - Y||_F^2 + 0.5 * lambda * ||C||_F^2

with lambda = 0.65. P, Q, and C0 are deterministic formulas listed in `instance.json`.

Report the minimum objective value and a checksum of the optimal core matrix.

The dense formulation introduces one response variable per segment-item pair plus linking equations. A matrix-aware formulation eliminates those dense variables and solves only the 4-by-4 core by Gram-matrix normal equations.
